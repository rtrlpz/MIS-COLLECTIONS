DAX Measure Storage
Where and how to store DAX measures in Power BI for a professional, maintainable project structure.
The correct approach: empty measure tables

Never store measures inside your data tables. When a table is renamed, refreshed, or replaced, orphaned measures break silently. Create dedicated empty tables using a single-row DAX expression — no data loads, no relationships needed.

Use an underscore prefix on measure table names. Power BI sorts the field list alphabetically, so _Contact & Volume pins above accounts, keeping your measures always visible at the top.

Three tables is the right split for this project — it keeps each group under 15 measures, which is the threshold where a collapsed folder in the field list stops being scannable.

Create these three tables in Power BI (Modeling → New Table)
