## LibreOffice ↔ Excel translation

Medium was written with Excel in mind. You use LibreOffice Calc, so use this
table whenever a task names an Excel feature.

| Concept | In Excel | In LibreOffice Calc |
|---|---|---|
| Formula-driven table | `Insert → Table` (`tblDaily[Date]`) | `Sheet → Named Ranges and Expressions → Define` |
| Structured references | `tblDaily[Contacts]` | Not supported — use the named range directly |
| Lookup | `XLOOKUP` | `XLOOKUP` only in Calc 24.8+; otherwise `VLOOKUP` or `INDEX/MATCH` |
| Pivot table | `Insert → PivotTable` | `Insert → Pivot Table` |
| Pivot filter | Slicer | Pivot **Page Field** (Calc has no slicer) |
| Refresh a pivot | `Refresh` | Right-click pivot → `Refresh`, or `Data → Refresh Range` |
| Import/refresh CSV | `Data → Get Data` (Power Query) | `Sheet → Link to External Data`, then `Data → Refresh Range` |
| Conditional formatting | `Home → Conditional Formatting` | `Format → Conditional → Manage` |
| Dropdown validation | `Data → Data Validation` | `Data → Validity` |
| Freeze header row | `View → Freeze Panes` | `View → Freeze Rows and Columns` |
| Print area | `Page Layout → Print Area` | `Format → Print Ranges → Define` |
| PDF | `File → Export` | `File → Export as PDF` |

**Formula separator warning.** LibreOffice usually separates formula arguments
with **semicolons** (`;`), not commas (`,`). If you copy an Excel-style formula
and see `Err:509`, replace every comma with a semicolon. The formulas in this
file are written the LibreOffice way.

## Task 1 — Create the project structure and recreate the source data

**Type:** Manual + SQL · **Not Python**

**Goal:** Learn where the pack's numbers come from, and create the two CSV
files that the rest of Medium depends on. You are not copying Basic's CSV —
you are exporting **daily × team** data, which Basic never had.

**What to create:**
- `learning/excel/medium/data/raw_employee.csv`
- `learning/excel/medium/data/raw_daily_mis_team.csv`
- The `data/`, `work/`, `work/scripts/`, `work/exports/` folders

**Steps:**

1. Create the folders listed at the top of this file.
2. Start the database from the project root:

   ```
   docker compose --env-file .env -f database/docker-compose.yml up -d
   ```

3. Open pgAdmin (or `psql`) and connect to `MIS_CollectionsDB` on
   `localhost:5433`. Use the credentials from your `.env` file.
4. Run this query to export the agent roster:

   ```sql
   SELECT agent_id, agent_name, team_name
   FROM dim_employees
   WHERE is_current = TRUE
   ORDER BY agent_id;
   ```

5. Save the result as `learning/excel/medium/data/raw_employee.csv`.
   - pgAdmin: right-click the result grid → **Save Data** → CSV.
   - psql: `\copy (SELECT ...) TO '.../raw_employee.csv' CSV HEADER`
6. Run this query to build the daily × team data:

   ```sql
   WITH activity AS (
       SELECT i.interaction_date AS date,
              e.team_name        AS team,
              COUNT(*)           AS contacts,
              SUM(COALESCE(i.calls_connected, 0)) AS connects,
              COUNT(*) FILTER (WHERE i.rpc_flag)  AS rpcs
       FROM fact_interactions i
       JOIN dim_employees e ON e.agent_id = i.agent_id
       GROUP BY 1, 2
   ),
   promises AS (
       SELECT p.ptp_date AS date, e.team_name AS team,
              COUNT(*) AS promises,
              COUNT(*) FILTER (WHERE p.status = 'Kept')   AS kept,
              COUNT(*) FILTER (WHERE p.status = 'Broken') AS broken
       FROM fact_ptp_log p
       JOIN dim_employees e ON e.agent_id = p.agent_id
       GROUP BY 1, 2
   ),
   payments AS (
       SELECT pay.payment_date AS date, e.team_name AS team, COUNT(*) AS payments
       FROM fact_payments pay
       JOIN dim_employees e ON e.agent_id = pay.agent_id
       GROUP BY 1, 2
   )
   SELECT COALESCE(a.date, pr.date, pa.date) AS "Date",
          COALESCE(a.team, pr.team, pa.team) AS "Team",
          COALESCE(a.contacts, 0) AS "Contacts",
          COALESCE(a.connects, 0) AS "Connects",
          COALESCE(a.rpcs, 0)     AS "RPCs",
          COALESCE(pr.promises, 0) AS "Promises",
          COALESCE(pa.payments, 0) AS "Payments",
          COALESCE(pr.kept, 0)     AS "Kept",
          COALESCE(pr.broken, 0)   AS "Broken"
   FROM activity a
   FULL OUTER JOIN promises pr
       ON pr.date = a.date AND pr.team = a.team
   FULL OUTER JOIN payments pa
       ON pa.date = COALESCE(a.date, pr.date)
      AND pa.team = COALESCE(a.team, pr.team)
   ORDER BY 1, 2;
   ```

7. Save the result as `learning/excel/medium/data/raw_daily_mis_team.csv`.
8. Open both CSV files in Calc. In the import dialog choose **Comma** as the
   separator and tick **Detect special numbers** so dates become real dates.

**Expected result:** Two CSV files. The team CSV has the columns
`Date, Team, Contacts, Connects, RPCs, Promises, Payments, Kept, Broken`, covers
2025-01-01 to 2025-12-31, and contains the eight teams. Kept and Broken are the
resolved-promise counts behind KP%.

**Beginner check:** Open the team CSV. The first date is a real date (right-
aligned, not text), the last date is 2025-12-31, and the Team column shows
`Team 1` … `Team 8`. Sort by Team once and confirm there are eight groups.

**Files created/modified:** `data/raw_employee.csv`,
`data/raw_daily_mis_team.csv`

**Note:** Payments with an empty `agent_id` are self-cures. They cannot be
attributed to a team, so they do not appear in the team rows. That is
expected — not a bug.

**Fallback if the database is not available:** the project's generated CSVs
under `data_sources/raw/` can produce the same file. This is *data
preparation*, not the Excel automation you are learning, so run it once:

```python
import glob
import pandas as pd

emp = pd.read_csv("data_sources/raw/shared/Dim_Employees.csv",
                  usecols=["agent_id", "team_name", "is_current"])
emp = emp[emp["is_current"] == True]

frames = []
for month in sorted(glob.glob("data_sources/raw/*_2025")):
    inter = pd.read_csv(f"{month}/Fact_Interactions.csv",
                        parse_dates=["interaction_date"])
    ptp = pd.read_csv(f"{month}/Fact_PTP_Log.csv", parse_dates=["ptp_date"])
    pay = pd.read_csv(f"{month}/Fact_Payments.csv", parse_dates=["payment_date"])

    inter = inter.merge(emp[["agent_id", "team_name"]], on="agent_id")
    ptp = ptp.merge(emp[["agent_id", "team_name"]], on="agent_id")
    pay = pay.merge(emp[["agent_id", "team_name"]], on="agent_id")

    a = (inter.groupby(["interaction_date", "team_name"])
               .agg(Contacts=("interaction_id", "size"),
                    Connects=("calls_connected", "sum"),
                    RPCs=("rpc_flag", "sum")).reset_index()
               .rename(columns={"interaction_date": "Date",
                                "team_name": "Team"}))
    p = (ptp.groupby(["ptp_date", "team_name"])
             .agg(Promises=("ptp_id", "size"),
                  Kept=("status", lambda s: (s == "Kept").sum()),
                  Broken=("status", lambda s: (s == "Broken").sum()))
             .reset_index()
             .rename(columns={"ptp_date": "Date", "team_name": "Team"}))
    q = (pay.groupby(["payment_date", "team_name"]).size()
            .rename("Payments").reset_index()
            .rename(columns={"payment_date": "Date", "team_name": "Team"}))
    frames.append(a.merge(p, how="outer", on=["Date", "Team"])
                   .merge(q, how="outer", on=["Date", "Team"]))

out = pd.concat(frames).fillna(0)
out["RPCs"] = out["RPCs"].astype(int)
out.to_csv("learning/excel/medium/data/raw_daily_mis_team.csv", index=False)
```

## Task 3 — Import the data and create named ranges

**Type:** Manual, LibreOffice Calc

**Goal:** Learn the "one producer, many consumers" idea. All raw values live
on `Data`; everything else points at it. You will also learn Calc's
equivalent of an Excel Table: **named ranges**.

**What to create:** The `Data` sheet plus named ranges `tblDate`, `tblTeam`,
`tblContacts`, `tblConnects`, `tblRPCs`, `tblPromises`, `tblPayments`,
`tblKept`, `tblBroken`, `tblMonth`, and one helper column.

**Steps:**

1. Open `data/raw_daily_mis_team.csv` in Calc:
   **File → Open** → select the CSV → in the import dialog choose **Comma**
   and tick **Detect special numbers** → OK.
2. Select all the data (`Ctrl+A`) → copy (`Ctrl+C`).
3. Go back to your workbook, click the `Data` sheet, click cell `A1`, paste
   (`Ctrl+V`).
4. Make sure row 1 contains these headers, in this order:
   `A1 Date`, `B1 Team`, `C1 Contacts`, `D1 Connects`, `E1 RPCs`,
   `F1 Promises`, `G1 Payments`, `H1 Kept`, `I1 Broken`, `J1 Month`.
5. In `J2` type:

   ```
   =DATE(YEAR(A2);MONTH(A2);1)
   ```

   This turns the date into the first day of its month. Fill it down to the
   last data row (double-click the small square at the bottom-right of `J2`,
   or drag it down).
6. Format the columns:
   - `A` → `yyyy-mm-dd`
   - `J` → `yyyy-mm`
   - `C:I` → `#,##0`
   Use **Format → Cells** (or `Ctrl+1`).
7. Define the named ranges:
   **Sheet → Named Ranges and Expressions → Define**.
   Add one row for each name:

   | Name | Range |
   |---|---|
   | `tblDate` | `$Data.$A$2:$A$10000` |
   | `tblTeam` | `$Data.$B$2:$B$10000` |
   | `tblContacts` | `$Data.$C$2:$C$10000` |
   | `tblConnects` | `$Data.$D$2:$D$10000` |
   | `tblRPCs` | `$Data.$E$2:$E$10000` |
   | `tblPromises` | `$Data.$F$2:$F$10000` |
   | `tblPayments` | `$Data.$G$2:$G$10000` |
   | `tblKept` | `$Data.$H$2:$H$10000` |
   | `tblBroken` | `$Data.$I$2:$I$10000` |
   | `tblMonth` | `$Data.$J$2:$J$10000` |

   10,000 is a safe upper bound — the names cover the data even when rows are

8. Save.

## Task 4 — Write the SUMIFS monthly summary

**Type:** Manual, LibreOffice Calc

**Goal:** Build a summary that recalculates from `Data` — no copy-paste
numbers. Learn how `SUMIFS` works and how a month-over-month delta is
calculated.

**What to create:** The `Summary` sheet, rows 4–16.

**Steps:**

1. On `Summary`:
   - `A1`: `Monthly Summary` (bold, size 14)
   - Row 4 headers: `A4 Month`, `B4 Contacts`, `C4 Connects`, `D4 RPCs`,
     `E4 RPC %`, `F4 Promises`, `G4 Payments`, `H4 KP %`,
     `I4 Promises Δ MoM`
2. In `A5` type `2025-01-01`. In `A6` type `2025-02-01`. Select both and drag
   the fill handle down to `A16` so you have all 12 months. Format `A5:A16`
   as `yyyy-mm`.
3. In `B5` type:

   ```
   =SUMIFS(tblContacts;tblMonth;$A5)
   ```

   This adds every `Contacts` value whose `Month` equals the month in `A5`.
4. In `C5` type `=SUMIFS(tblConnects;tblMonth;$A5)`.
5. In `D5` type `=SUMIFS(tblRPCs;tblMonth;$A5)`.
6. In `F5` type `=SUMIFS(tblPromises;tblMonth;$A5)`.
7. In `G5` type `=SUMIFS(tblPayments;tblMonth;$A5)`.
8. In `E5` type `=IFERROR(D5/C5;0)` and format `E5` as `0.0%`.
   This is RPCs ÷ Connects.
9. In `H5` type:

   ```
   =IFERROR(SUMIFS(tblKept;tblMonth;$A5)/
            (SUMIFS(tblKept;tblMonth;$A5)+SUMIFS(tblBroken;tblMonth;$A5));0)
   ```

   Format `H5` as `0.0%`. This is KP% — Kept ÷ (Kept + Broken). `Pending`
   promises stay out of the denominator.
10. In `I6` type `=F6-F5` and format `I6:I16` as `+#,##0;-#,##0;0`.
    This is this month's promises minus last month's.
11. Select `B5:H5` and drag the fill handle down to row 16.
12. Select `I6` and drag down to `I16`.
13. Save.

**Expected result:** Twelve month rows with totals, RPC%, KP%, and a
month-over-month promise delta.

**Beginner check:** Go to `Data`, pick one Promises cell and add `100` to it.
Return to `Summary`: that month's `F` and the next month's `I` must change.
Now type `=SUM(tblPromises)` in an empty cell — it must equal the sum of
`F5:F16`. Delete the test cell. Check one `H` cell by hand:
Kept ÷ (Kept + Broken) for that month.

**Files created/modified:** `work/daily_mis_medium.xlsx`

## Task 5 — Add RAG conditional formatting from Parameters

**Type:** Manual, LibreOffice Calc

**Goal:** Learn rule-based colouring. The thresholds live on `Parameters`, so
strategy can tune them without editing formulas. Red/amber/green is the
standard MIS "ten-second read".

**What to create:** Threshold cells on `Parameters` and three conditional
formatting rules on `Summary!H5:H16`.

**Steps:**

1. On `Parameters`:
   - `A1`: `Team`
   - `A2:A9`: `Team 1` … `Team 8`
   - `D1`: `Threshold`
   - `D2`: `KP% amber`, `E2`: `0.68` (format `0.0%`)
   - `D3`: `KP% green`, `E3`: `0.80` (format `0.0%`)
2. On `Summary`, select `H5:H16`.
3. **Format → Conditional → Manage → Add**.
4. Rule 1 (green):
   - Condition: **Cell value is** → **greater than or equal to**
   - Value: `$Parameters.$E$3`
   - New Style → Background `#00B050`, Font color white
5. Rule 2 (amber):
   - Condition: **Cell value is** → **between**
   - Values: `$Parameters.$E$2` and `$Parameters.$E$3`
   - New Style → Background `#FFC000`
6. Rule 3 (red):
   - Condition: **Cell value is** → **less than**
   - Value: `$Parameters.$E$2`
   - New Style → Background `#FF0000`, Font color white
7. Use **Move Up** so the green rule is first.
8. Test: change `E3` to `0.90` → almost everything repaints. Set it back to
   `0.80`.

**Expected result:** The KP% cells colour themselves, and changing a
threshold repaints the summary instantly.

**Beginner check:** Set `E2` and `E3` both to `0`. Every KP% cell must turn
green. Restore `0.68` and `0.80`. Hover over a cell to read its value and
confirm the colour matches the rule.

**Important:** KP% is stored as a decimal (`0.80`), so the thresholds must
also be decimals (`0.68`, `0.80`), not `68` and `80`. The 0.68 amber bound is
the project rule: amber starts at 85% of the 80% goal. If you type `68`, the
comparison is wrong.

**Files created/modified:** `work/daily_mis_medium.xlsx`

## Task 8 — Refresh the pack from the CSV

**Type:** Manual, LibreOffice Calc

**What to create:** A `RawRefresh` sheet linked to the CSV, plus a documented

**Expected result:** Editing the CSV and refreshing updates the linked cells

**Beginner check:** Change a `Contacts` value in the CSV from `0` to `999`,
refresh, and see the linked cell and pivot total move. Change it back and

**Excel note:** Excel's `Data → Get Data` (Power Query) can also clean and
transform data step by step, append files, and load to the Data Model. Calc
can link and refresh; it cannot run Power Query steps. Write that difference
on the Cover.

## Task 9 — Set up printing and export a PDF

**Type:** Manual, LibreOffice Calc

**What to create:** Page settings on the important sheets and

**Steps:**

2. **Format → Print Ranges → Define**.

## Task 11 — Automate Data, named ranges, Summary, and RAG

**Type:** Python / openpyxl

**Goal:** Move the manual `Data` and `Summary` work into the script, including
conditional formatting.

**What to create:** `work/scripts/build_pack.py` (start from
`build_shell.py`) and an updated `work/daily_mis_auto.xlsx`.

**Steps:**

1. Copy `build_shell.py` to `build_pack.py`.
2. Add these imports at the top:

   ```python

   from openpyxl.styles import PatternFill, Border, Side
   from openpyxl.formatting.rule import CellIsRule
   from openpyxl.workbook.defined_name import DefinedName
   ```

3. After the sheet creation, build `Data`:

   ```python
   DATA_CSV = ROOT / "data" / "raw_daily_mis_team.csv"
   df = pd.read_csv(DATA_CSV, parse_dates=["Date"])
   df["Month"] = df["Date"].values.astype("datetime64[M]")

   ws_d = wb["Data"]
   headers = ["Date", "Team", "Contacts", "Connects", "RPCs",
              "Promises", "Payments", "Kept", "Broken", "Month"]
   ws_d.append(headers)
   for _, row in df.iterrows():
       ws_d.append([
           row["Date"].to_pydatetime(), row["Team"],
           int(row["Contacts"]), int(row["Connects"]), int(row["RPCs"]),
           int(row["Promises"]), int(row["Payments"]),
           int(row["Kept"]), int(row["Broken"]),
           row["Month"].to_pydatetime(),
       ])

   last = ws_d.max_row
   for r in range(2, last + 1):
       ws_d[f"A{r}"].number_format = "yyyy-mm-dd"
       ws_d[f"J{r}"].number_format = "yyyy-mm"
       for col in "CDEFGHI":
           ws_d[f"{col}{r}"].number_format = "#,##0"

   ws_d.freeze_panes = "A2"
   for col, width in {"A": 12, "B": 10, "C": 11, "D": 11,
                      "E": 9, "F": 11, "G": 11, "H": 9,
                      "I": 9, "J": 10}.items():
       ws_d.column_dimensions[col].width = width

   names = {
       "tblDate": "A", "tblTeam": "B", "tblContacts": "C",
       "tblConnects": "D", "tblRPCs": "E", "tblPromises": "F",
       "tblPayments": "G", "tblKept": "H", "tblBroken": "I",
       "tblMonth": "J",
   }
   for name, col in names.items():
       wb.defined_names.add(DefinedName(
           name, attr_text=f"Data!${col}$2:${col}$10000"))
   ```

4. Build `Summary` with formulas:

   ```python
   ws_s = wb["Summary"]
   ws_s["A1"] = "Monthly Summary"
   ws_s["A1"].font = Font(size=14, bold=True, color="262A76")
   head = ["Month", "Contacts", "Connects", "RPCs", "RPC %",
           "Promises", "Payments", "KP %", "Promises Δ MoM"]
   for c, text in enumerate(head, start=1):
       cell = ws_s.cell(row=4, column=c, value=text)
       cell.font = Font(bold=True, color="FFFFFF")
       cell.fill = PatternFill("solid", fgColor="262A76")
       cell.alignment = Alignment(horizontal="center")

   months = pd.date_range("2025-01-01", periods=12, freq="MS")
   formula_cols = {
       "B": "tblContacts", "C": "tblConnects", "D": "tblRPCs",
       "F": "tblPromises", "G": "tblPayments",
   }
   for i, month in enumerate(months, start=5):
       ws_s[f"A{i}"] = month.to_pydatetime()
       ws_s[f"A{i}"].number_format = "yyyy-mm"
       for col, name in formula_cols.items():
           ws_s[f"{col}{i}"] = f"=SUMIFS({name},tblMonth,$A{i})"
       ws_s[f"E{i}"] = f"=IFERROR(D{i}/C{i},0)"
       ws_s[f"E{i}"].number_format = "0.0%"
       ws_s[f"H{i}"] = (
           f"=IFERROR(SUMIFS(tblKept,tblMonth,$A{i})/"
           f"(SUMIFS(tblKept,tblMonth,$A{i})+SUMIFS(tblBroken,tblMonth,$A{i})),0)")
       ws_s[f"H{i}"].number_format = "0.0%"
       if i > 5:
           ws_s[f"I{i}"] = f"=F{i}-F{i-1}"
           ws_s[f"I{i}"].number_format = "+#,##0;-#,##0;0"

   ws_s.freeze_panes = "A5"
   ws_s.column_dimensions["A"].width = 12
   for col in "BCDEFGHI":
       ws_s.column_dimensions[col].width = 14
   ```

5. Add the thresholds and RAG rules:

   ```python
   ws_p = wb["Parameters"]
   ws_p["A1"] = "Team"
   for i, team in enumerate(sorted(df["Team"].unique()), start=2):
       ws_p[f"A{i}"] = team
   ws_p["D1"] = "Threshold"
   ws_p["D2"] = "KP% amber"
   ws_p["E2"] = 0.68
   ws_p["E2"].number_format = "0.0%"
   ws_p["D3"] = "KP% green"
   ws_p["E3"] = 0.80
   ws_p["E3"].number_format = "0.0%"

   green = PatternFill("solid", fgColor="00B050")
   amber = PatternFill("solid", fgColor="FFC000")
   red   = PatternFill("solid", fgColor="FF0000")
   rng = "H5:H16"
   ws_s.conditional_formatting.add(rng, CellIsRule(
       operator="greaterThanOrEqual", formula=["Parameters!$E$3"], fill=green))
   ws_s.conditional_formatting.add(rng, CellIsRule(
       operator="between", formula=["Parameters!$E$2", "Parameters!$E$3"],
       fill=amber))
   ws_s.conditional_formatting.add(rng, CellIsRule(
       operator="lessThan", formula=["Parameters!$E$2"], fill=red))
   ```

6. Save the workbook at the end of the script and run it:
   `python learning/excel/medium/work/scripts/build_pack.py`
7. Open `daily_mis_auto.xlsx` in Calc.

**Expected result:** The generated `Data` sheet has all rows; `Summary` shows
12 months of totals; KP% cells are coloured by the rules.

## Task 13 — Reconcile against the source and do the final review

**Type:** Python / openpyxl

**Goal:** Build the audit habit: every shipped number must agree with the
source. A mismatch is a finding, not a rounding error.

**What to create:** A reconciliation function inside `build_pack.py` and a
final review of the whole pack.

**Steps:**

1. Add a reconciliation function:

   ```python
   import csv
   from openpyxl import load_workbook

   def reconcile(date_text, team):
       with open(ROOT / "data" / "raw_daily_mis_team.csv", newline="") as f:
           source = next(r for r in csv.DictReader(f)
                         if r["Date"] == date_text and r["Team"] == team)

       wb = load_workbook(OUT, data_only=True)
       ws = wb["Data"]
       for row in ws.iter_rows(min_row=2, values_only=True):
           if row[0].strftime("%Y-%m-%d") == date_text and row[1] == team:
               sheet = {
                   "Contacts": row[2], "Connects": row[3], "RPCs": row[4],
                   "Promises": row[5], "Payments": row[6],
                   "Kept": row[7], "Broken": row[8],
               }
               break

       for key, value in sheet.items():
           expected = int(source[key])
           if value != expected:
               print(f"FAIL {key}: sheet={value} source={expected}")
               return False
       print(f"PASS {date_text} / {team}: all seven metrics match")
       return True
   ```

2. Call it at the end of the script with a real date and team:

   ```python
   reconcile("2025-06-02", "Team 1")
   ```

3. Run the script and read the output.
4. Deliberately change one value in the workbook after generation, rerun the
   check, and confirm it reports `FAIL`. Restore it.
5. Final review checklist:
   - [ ] Six sheets in the fixed order, tabs coloured
   - [ ] `Data` has one row per date × team and a Month column
   - [ ] Summary totals equal `=SUM(tblPromises)` and match the manual workbook
   - [ ] KP% turns green/amber/red from the Parameters thresholds
   - [ ] Pivot (manual) and Dashboard chart work
   - [ ] The CSV refresh routine is documented on the Cover
   - [ ] Dropdown refuses invalid team names
   - [ ] ChangeLog has at least three real entries
   - [ ] PDF is landscape, one page wide, header repeats
   - [ ] Reconciliation prints `PASS`

**Expected result:** A pack that proves its own numbers, plus a reconciliation
line in the script output.

**Beginner check:** The script prints `PASS 2025-06-02 / Team 1`. Change one
